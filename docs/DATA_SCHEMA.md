# MLBB Meta Analyser — Data Schemas

This document defines the schema of all processed JSON datasets, exports, and CSV structures generated by the pipeline.

---

## 1. Processed Data Files

### 1.1 `data/processed/heroes_catalog.json`
Array of canonical hero objects extracted from Moonton CDN:
```typescript
interface HeroCatalogEntry {
  heroid: number;                 // Unique Moonton Hero ID (e.g. 1)
  name: string;                   // Hero Name (e.g. "Miya")
  roles: string[];                // Roles: ["Marksman"], ["Tank", "Support"], etc.
  lanes: string[];                // Lanes: ["Gold Lane"], ["Exp Lane", "Roam"], etc.
  speciality: string[];           // ["Reap", "Damage"]
  difficulty: string;             // Difficulty rating (0 - 100)
  head: string;                   // Official HD portrait URL (100_...png)
  smallmap: string;               // Mini avatar icon URL
  painting: string;               // Full splash artwork URL
  skills: {
    id: number;
    name: string;
    desc: string;                 // Plain text description without HTML font tags
    cost: string;                 // Cooldown and mana cost
    icon: string;                 // Official skill icon URL
    tags: string[];               // e.g. ["AOE", "CC", "Blink"]
  }[];
}
```

### 1.2 `data/processed/ranks/{rank}_{timeframe}.json`
Array of heroes ranked by win rate for that specific slice (e.g. `mythic_1d.json`, `glory_7d.json`):
```typescript
interface HeroRankRecord {
  ranking: number;                // Rank position (1-indexed)
  heroid: number;                 // Hero ID
  name: string;                   // Hero name
  head: string;                   // Official portrait URL
  roles: string[];                // Array of roles
  lanes: string[];                // Array of recommended lanes
  win_rate: number;               // Raw float (e.g. 0.594379)
  win_rate_pct: number;           // Percentage (e.g. 59.44)
  pick_rate: number;              // Raw float (e.g. 0.011859)
  pick_rate_pct: number;          // Percentage (e.g. 1.19)
  ban_rate: number;               // Raw float (e.g. 0.146545)
  ban_rate_pct: number;           // Percentage (e.g. 14.65)
  meta_score: number;             // Composite Meta Score (0 - 100)
  tier: "S+" | "S" | "A" | "B" | "C" | "D";
  timeframe: string;              // "1d", "3d", "7d", "15d", "30d"
  timeframe_name: string;         // "Past 1 day", etc.
  rank: string;                   // "all", "epic", "legend", "mythic", "mythical_honor", "mythical_glory"
  rank_name: string;              // "Mythical Glory+", etc.
  counters: SubHeroRecord[];      // Top 5 counter heroes
  synergies: SubHeroRecord[];     // Top 5 teammate synergy heroes
}

interface SubHeroRecord {
  heroid: number;
  name: string;
  head: string;
  increase_win_rate: number;      // Float impact
  increase_win_rate_pct: number;  // e.g. +3.53%
}
```

### 1.3 `data/processed/matrices/counters_matrix.json` & `synergies_matrix.json`
Key-value mappings where `key = heroid` and `value = SubHeroRecord[]`.
Enables instant $O(1)$ lookup for any hero's counters and synergies in the web UI.

## 2. Exports

### 2.1 Tabular CSV: `data/exports/mlbb_meta_latest.csv`
Contains 3,990 rows (133 heroes $\times$ 30 rank/timeframe slices).
Columns:
- `timeframe`: e.g. `1d`
- `timeframe_name`: e.g. `Past 1 day`
- `rank`: e.g. `mythic`
- `rank_name`: e.g. `Mythic`
- `ranking`: Rank index (1 - 133)
- `heroid`: Hero ID
- `name`: Hero name
- `roles`: Comma-separated roles
- `lanes`: Comma-separated lanes
- `win_rate_pct`: e.g. `59.44`
- `pick_rate_pct`: e.g. `1.19`
- `ban_rate_pct`: e.g. `14.65`
- `meta_score`: Score 0 - 100
- `tier`: Tier (S+, S, A, B, C, D)
- `counter_1` ... `counter_5`: Names of top 5 counters
- `synergy_1` ... `synergy_5`: Names of top 5 synergies
- `avatar_url`: Official HD headshot CDN URL

### 2.2 Markdown Report: `data/exports/MLBB_META_REPORT.md`
Human and AI-readable tabular report featuring:
1. Executive Summary of Mythical Glory+ Top Performers
2. Priority Bans in Mythic
3. Most Popular Heroes across All Ranks
